# SwiftUI 开发交接包与 iPhone 适配

用户将交付包提供给在 Xcode 中开发 SwiftUI 的 Agent。HTML 用于查看设计和操作流程；设计规格、状态规则与独立素材支持原生重建，不把 CSS 逐行转换、WebView 包装或整屏图片铺底作为默认实现方式。

## 交付内容

- `index.html` 与相对路径引用的样式、脚本：可操作的原型，采用稳定页面 ID、可理解的组件名称和集中管理的设计变量。
- `design.md`：iOS 设计规范与适配规则，作为设计数值的权威来源。
- `screens.md`：页面 ID、内容结构、动作、状态转移、返回/取消、保存与失败恢复；标明模拟服务。
- `tokens.json`：与 design.md 对齐的语义颜色、间距、圆角和尺寸，不从生成图猜出多套互相矛盾的数值。
- `assets/images/`、`assets/icons/`、`assets/manifest.json`：独立素材与用途、资源名称、尺寸、裁切、生成来源。需要新图片时单独使用 Image Gen 生成并接入，不将整屏 UI 图用作内容素材。可附经过检查的 Assets.xcassets；标准操作图标记录 SF Symbols 名称与目标系统可用性。
- `references/`：确认的低保真和高保真，标注对应版本；不把全部废弃候选塞进最终包。
- `SWIFTUI-HANDOFF.md`：实现优先级、目标 iOS、原生组件映射、适配与原生验证清单。导航、列表、表单、弹层等按目标版本选择合适 SwiftUI 组件，不以网页实现细节为约束。
- `README.md` 与 `evidence/`：启动方式、资源路径、页面入口、已验证矩阵、截图和未覆盖项。

若页面需本地服务，提供准确启动命令及依赖要求；不能声称任何 HTML 都能双击完整运行。打包前验证入口、引用路径、素材和文档齐全，不依赖作者机器上的绝对路径或外部临时服务。排除缓存、凭据、node_modules 和无关文件。生成命名明确的 ZIP，提供下载链接；用户要求保存桌面时复制到桌面，避免覆盖同名旧包。

## design.md 必须可指导原生实现

写清以下内容，区分 Apple 官方指导、项目自定参数与 HTML 模拟限制，附官方来源和核对日期。按 apple-integration.md 使用 reviewer 规则索引并核对实际采用的主题。

- 字体：系统/自定义字体、语义文本角色、基准字号（pt）、字重、行距与换行、Dynamic Type 策略。HTML px 是预览映射，不等于设备物理像素；不只提供固定 CSS 字号。
- 布局：页面边距、组内/组间距离、列表行内边距、对齐关系、固定/自适应/最小尺寸与滚动容器。
- 组件：按钮、输入框、卡片、标签与弹层的圆角、边框、颜色、各状态；可见大小与实际触控范围分别记录。
- 适配：安全区、底部操作区、键盘出现时的处理、小屏重排、大字重排、图片比例与裁切焦点。
- 可访问性：语义标签、读屏顺序、对比度、非颜色反馈、减少动态效果；未验证原生能力明确标注。

低保真与页面规格决定内容和行为，高保真与 design.md 决定视觉。系统组件行为遵循目标 iOS 原生规范；发现设计冲突时记录必要修正，不照搬生成图中的错误。

## design.md 中的多尺寸 iPhone 说明

交付原型沿用已确认的基准尺寸、内容与布局。不同 iPhone 尺寸的适配只作为设计文档中的原生实现指导，不默认改变原型、制作多尺寸版本或增加截图矩阵。以下规则写给下游 SwiftUI Agent，按页面特点简要说明即可；原生实现应按可用逻辑宽高布局，不将基准画面整体缩放。

- 优先使用内容驱动的高度、弹性宽度和合理最小/最大约束。保留文字与数量的优先级，避免绝对坐标拼屏。
- 窄屏允许标题、说明及操作组合理换行；必要时并排按钮改纵排。不要通过整体缩小字体和触控区域硬塞内容。
- 短屏将次要内容自然滚入屏下，主操作保持可达；给固定底栏预留内容空间。大屏展示更多内容或适度留白，不机械放大所有控件。
- 图片沿用确定的宽高比与裁切焦点；图片高度不得随屏幕增长而挤走核心操作。
- 不硬编码某款设备的状态栏、顶部挖孔或底部安全区高度到 SwiftUI；原型外壳与原生内容分离。键盘适配与安全区规则必须交给下游 Agent。
- 字体随用户设置放大时允许行高增长、按钮文字换行及布局重排；固定高列表不得裁掉大字。设备像素比放大截图不算大字测试。

## 验证责任

本阶段在已确认的基准视口验证 HTML 原型的视觉与交互。design.md 提醒下游覆盖较小、常规和较大 iPhone，依据实际支持设备选择模拟器；不在设计阶段固定额外机型或尺寸清单。

SwiftUI 交接说明下游需验证不同屏幕下的长文字、图片裁切、底栏遮挡、滚动和主要操作可达性，并检查 Dynamic Type、键盘、安全区、VoiceOver 和导航。未经 Xcode 构建和模拟器运行，不声称 SwiftUI 已编译、原生适配通过或实现像素级还原。用户另行要求多尺寸原型时，才扩大当前交付范围。
